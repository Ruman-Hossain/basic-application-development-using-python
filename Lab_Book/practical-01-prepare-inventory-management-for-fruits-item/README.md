# 🍎 Fruit Inventory Management System

A simple CLI-based inventory system for managing fruit items using Python.

---

## 📁 Features

- Add new fruit items
- Store data in CSV
- View inventory summary
- Maintain job logs

---

## 🧱 Project Structure

- `main.py` → Entry point
- `data_input.py` → Handles user input
- `storage.py` → CSV storage logic
- `summary.py` → Display inventory
- `logger.py` → Logging operations
- `utils.py` → Utility functions

---

## ⚙️ Requirements

- Python 3.x

(No external libraries required)

---

## ▶️ How to Run

### 1. Clone / Download Project

```bash
git clone <your-repo-url>
cd fruit_inventory
```
## 2. Run Application
```bash
python main.py
```
