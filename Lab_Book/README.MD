# 📓 Jupyter Installation Guide

Get up and running with Project Jupyter on your computer using Python.

---

## 📦 Overview

Project Jupyter tools are available via the Python Package Index (PyPI).

This guide uses `pip` (recommended).  
If you need environment management, you can use:
- conda  
- mamba  
- pipenv  
- Homebrew  

---

## 🚀 JupyterLab

JupyterLab is the modern interface for Project Jupyter.

### Install
pip install jupyterlab

Note: If using conda or mamba, it is recommended to use the `conda-forge` channel.

### Run
jupyter lab

---

## 📘 Jupyter Notebook (Classic)

The classic notebook interface.

### Install
pip install notebook

### Run
jupyter notebook

---

## 🎨 Voilà

Voilà allows you to convert notebooks into standalone web applications.

### Install
pip install voila

### Run
voila

---

## 🍺 Homebrew Installation (macOS / Linux)

brew install jupyterlab

## 🧠 Notes

- Ensure Python is installed before running commands  
- Use virtual environments for better dependency management  
- `.ipynb` files are best for learning and analysis  
- Use `.py` scripts for CLI-based applications  

---

## ⚠️ Common Tips

pip install ipykernel

- Install Python extension in VS Code  
- Install Jupyter extension in VS Code  
- Select correct kernel before running notebook
